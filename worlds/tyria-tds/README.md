# Tyria — Les Terres de Sang (template de monde)

Monde complet TDS prêt à importer dans Celeste Virtual Dungeon : **12 domaines, 66 provinces,
124 holdings**, carte stratégique (positions + adjacences + image), **11 lignées de sang,
118 armées**, 169 entrées de lore avec **111 points sur la carte**, routes commerciales et
relations diplomatiques.

C'est un **template** : pas de personnages joueurs (hors PNJ/régents), pas d'historique de
partie, saison 1 vierge.

## Installation
- **App à jour** : onglet store → « 🌍 Tyria — Les Terres de Sang » → **Installer** (crée une
  nouvelle campagne, en 1 clic).
- **Manuel** : télécharger `tyria-tds-template.zip` → dans Celeste, **« Importer une campagne »**.

Pour le bestiaire SRD (monstres/sorts) référencé, installer aussi le module **srd-5e**.

Format : export campagne Celeste **1.2** (.zip). Intégrité : `sha256` dans `registry.json`.
